PDF 합치기

여러 PDF를 원하는 순서로 합치세요. 페이지 범위 선택부터 순서 변경까지, 파일 업로드 없이 브라우저에서 처리합니다.

무료회원가입 없음브라우저에서 처리

1파일 선택

↥PDF 파일을 여기에 놓으세요

PDF 2~20개 · 합계 150MB · 최대 1,000페이지

선택한 파일이 없습니다

    파일 준비 완료

    결과 다운로드 ↓

    이렇게 사용하세요

    1. 합칠 문서를 두 개 이상 선택합니다.
    2. 위아래 버튼으로 파일 순서를 정합니다.
    3. 합치기를 누르고 완료된 파일을 저장합니다.

    암호·전자서명 문서는 지원하지 않습니다. 입력 양식은 별도 동의를 받아 일반 페이지로 바꿀 수 있습니다.

    선택한 파일은 브라우저 안에서 처리합니다. 파일 본문과 이름을 서버로 전송하지 않습니다.

    필요한 작업을, 간단하게

    • 문서별 페이지 범위 선택
    • 버튼으로 파일 순서 변경
    • 원본 페이지 크기·회전 방향 유지

    암호·전자서명 문서는 지원하지 않습니다. 입력 양식은 별도 동의를 받아 일반 페이지로 바꿀 수 있습니다.

    원본은 그대로 둡니다

    입력 파일을 덮어쓰지 않습니다. 결과를 새 파일로 저장하고, 실제 제출·인쇄 전에 내용과 순서를 확인해 주세요. 문서 안의 글꼴은 파일을 여는 환경에 따라 다르게 보일 수 있습니다.

    기능 제한과 지원 범위는 아래 안내에서 확인할 수 있습니다.

    자주 묻는 질문

    페이지를 일부만 합칠 수 있나요?

    각 파일 아래 페이지 칸에 1,3-5처럼 입력하세요. 비워 두면 전체 페이지를 사용합니다. 적힌 순서대로 결합하며 범위 중복은 오류로 안내합니다.

    합친 PDF의 품질이 떨어지나요?

    페이지를 이미지로 다시 만들지 않고 원본 페이지를 복사합니다. 일반 PDF의 텍스트와 그림은 유지되지만 책갈피·전자서명·문서 단위 첨부파일의 보존은 지원하지 않습니다.

    입력 가능한 양식도 유지되나요?

    이 도구는 여러 PDF의 입력 양식을 하나의 편집 가능한 양식으로 결합하지 않습니다. 양식 파일은 기본적으로 거절하며, 변환에 동의한 경우에만 현재 보이는 내용으로 고정합니다. 이후 결과 파일에서는 양식을 수정할 수 없습니다.

    스마트폰에서도 되나요?

    최신 브라우저에서 파일 앱으로 PDF를 선택할 수 있습니다. 큰 문서는 기기의 메모리에 따라 처리하지 못할 수 있으므로 나눠서 합쳐 주세요.

    개인정보·이용 안내

    선택한 파일은 현재 브라우저에서 처리합니다. 이 앱은 파일이나 입력 내용을 저장하는 서버를 사용하지 않습니다. 접속 통계 및 광고를 위해 Google Analytics·Tag Manager·AdSense와 Cloudflare 분석 도구를 사용하며, 이들 서비스에는 일반적인 접속 정보가 전달될 수 있습니다. 파일 내용·이름·QR 입력값을 분석 이벤트로 보내지 않습니다.

    도구는 무료로 제공됩니다. 중요한 문서는 원본을 보관하고 결과를 확인한 뒤 사용하세요. 문의: NaNa Lab 문의.
